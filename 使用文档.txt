一、零基础环境搭建（全新电脑从零开始）
================================================================================

  以下步骤适用于一台什么都没装过的全新 Windows 电脑，依次执行即可。

--------------------------------------------------------------------------------
1.1  安装 WSL2
--------------------------------------------------------------------------------

  打开 PowerShell（管理员），执行：

      wsl --install

  等待安装完成，重启电脑。

  重启后验证：

      wsl --version

  显示 WSL 版本 2.x.x 即成功。

--------------------------------------------------------------------------------
1.2  安装 Docker Desktop
--------------------------------------------------------------------------------

  浏览器打开 https://www.docker.com/products/docker-desktop/
  下载 Windows 版，双击安装。

  安装时勾选 "Use WSL 2 instead of Hyper-V"。
  安装完成后启动 Docker Desktop，等右下角图标变绿。

  验证：

      docker --version

--------------------------------------------------------------------------------
1.3  配置 Docker 镜像加速（国内用户必须）
--------------------------------------------------------------------------------

  右键右下角 Docker 图标 → Settings → Docker Engine
  将内容替换为：

      {
        "builder": {
          "gc": {
            "defaultKeepStorage": "20GB",
            "enabled": true
          }
        },
        "experimental": false,
        "registry-mirrors": [
          "https://docker.1ms.run",
          "https://docker.xuanyuan.me"
        ]
      }

  点击 "Apply & restart"。
  验证：docker pull hello-world

--------------------------------------------------------------------------------
1.4  获取项目代码
--------------------------------------------------------------------------------

  将项目放到任意位置，例如 E:\jwb\wasteNews\

  确保目录结构包含：

      E:\jwb\wasteNews\
      ├── docker-compose.yml
      ├── Dockerfile.backend
      ├── docker-entrypoint.sh
      ├── .env
      ├── main.py
      ├── requirements.txt
      ├── config/
      │   ├── db_conf.py
      │   └── redis_conf.py
      ├── crud/
      ├── models/
      ├── routers/
      ├── schemas/
      ├── services/
      │   ├── news_fetcher.py
      │   └── cache.py
      ├── utils/
      └── frontend/          ← 前端源码（复制 xwzx-news 并改名）
          ├── package.json
          ├── Dockerfile
          ├── nginx.conf
          └── src/

  重点：前端源码文件夹必须命名为 frontend 并放在 wasteNews 下。

二、Docker 一键部署（推荐方式）
================================================================================

  适用场景：只想快速跑起来，不需要改代码。

--------------------------------------------------------------------------------
2.1  确认 .env 配置
--------------------------------------------------------------------------------

  用记事本打开 E:\jwb\wasteNews\.env，确认内容：

      MYSQL_ROOT_PASSWORD=123456
      MYSQL_DATABASE=news_app
      NEWS_FETCH_INTERVAL=30
      NEWS_TOTAL_COUNT=300
      FRONTEND_PATH=./frontend
      REDIS_URL=redis://redis:6379/0

  REDIS_URL 是新增的 Redis 连接地址，Docker 环境不用改。

--------------------------------------------------------------------------------
2.2  启动所有服务（四个容器）
--------------------------------------------------------------------------------

  PowerShell 执行：

      cd E:\jwb\wasteNews
      docker compose up -d

  首次启动会下载 4 个镜像（MySQL, Redis, Python, Node）并安装依赖，
  视网络情况需要 10-30 分钟。

  看到四行 Started 说明成功：

      ✔ Container wastenews-db         Started
      ✔ Container wastenews-redis      Started
      ✔ Container wastenews-backend    Started
      ✔ Container wastenews-frontend   Started

--------------------------------------------------------------------------------
2.3  查看运行状态
--------------------------------------------------------------------------------

      docker compose ps

  正常应看到四个容器都是 Up：

      wastenews-db        mysql:8.0            Up (healthy)
      wastenews-redis     redis:7-alpine       Up (healthy)
      wastenews-backend   wastenews-backend    Up
      wastenews-frontend  wastenews-frontend   Up

--------------------------------------------------------------------------------
2.4  查看启动日志
--------------------------------------------------------------------------------

      docker compose logs backend | tail -30

  正常日志应包含：

      Redis 连接成功
      新闻调度器已启动 — 每 30 分钟拉取一次
      浏览量定时任务已启动 — 每 5 分钟批量入库
      ✓ 成功插入 300 条新闻
      新闻库刷新完成! 当前保有 300 条

--------------------------------------------------------------------------------
2.5  打开应用
--------------------------------------------------------------------------------

  浏览器访问：http://localhost:8080

  测试账号：admin / 123456

三、本地开发环境搭建（不含 Docker）
================================================================================

  适用场景：需要改代码调试，前后端分别启动。需要额外安装 Redis。

--------------------------------------------------------------------------------
3.1  安装 Python 3.13
--------------------------------------------------------------------------------

  官网 https://www.python.org/downloads/ 下载安装，勾选 Add Python to PATH。

      python --version

--------------------------------------------------------------------------------
3.2  安装 Node.js 20
--------------------------------------------------------------------------------

  官网 https://nodejs.org/ 下载 LTS 版。

      node --version
      npm --version

--------------------------------------------------------------------------------
3.3  安装 MySQL 8.0 + Redis
--------------------------------------------------------------------------------

  MySQL：https://dev.mysql.com/downloads/installer/
  安装时 root 密码设为 123456，创建数据库：

      CREATE DATABASE news_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

  Redis：https://github.com/tporadowski/redis/releases
  下载 Windows 版 Redis，解压后双击 redis-server.exe 启动。

--------------------------------------------------------------------------------
3.4  启动后端
--------------------------------------------------------------------------------

      cd E:\jwb\wasteNews

      python -m venv .venv
      .venv\Scripts\activate
      pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

      python init_db.py
      uvicorn main:app --reload

  访问 http://localhost:8000 验证。

--------------------------------------------------------------------------------
3.5  启动前端
--------------------------------------------------------------------------------

  新终端：

      cd E:\BaiduNetdiskDownload\项目物料\03-前端项目代码\xwzx-news
      npm install
      npm run dev

  访问 http://localhost:5173。

四、常用命令速查
================================================================================

  【Docker 全服务】

  启动所有容器：            docker compose up -d
  停止所有容器：            docker compose down
  停止并清除所有数据：       docker compose down -v
  查看容器状态：            docker compose ps
  查看资源占用：            docker stats


  【各容器日志】

  后端日志（含 Redis/新闻调度器）： docker compose logs -f backend
  前端日志：                       docker compose logs -f frontend
  Redis 日志：                     docker compose logs -f redis
  MySQL 日志：                     docker compose logs -f db


  【容器操作】

  重启后端（触发新闻拉取）：   docker compose restart backend
  重建后端（依赖变更后）：      docker compose up -d --build backend
  重建前端（代码变更后）：      docker compose up -d --build frontend
  进入后端容器调试：            docker compose exec backend bash
  进入 Redis 容器：             docker compose exec redis redis-cli
  进入 MySQL 容器：             docker compose exec db mysql -uroot -p123456


  【Redis 调试命令（进入 redis-cli 后）】

  查看所有缓存键：      KEYS *
  查看新闻列表缓存：     KEYS news:list:*
  查看 Token 缓存：      KEYS token:user:*
  查看浏览量计数：       HGETALL news:views:batch
  查看某键的 TTL：       TTL news:detail:1
  手动清除新闻缓存：     KEYS news:* | xargs redis-cli DEL
  查看内存使用：         INFO memory


  【本地开发模式】

  启动后端：                uvicorn main:app --reload
  启动前端：                npm run dev
  初始化数据库：            python init_db.py
  启动 Redis（Windows）：   redis-server.exe

--------------------------------------------------------------------------------
5.3  新闻自动更新说明
--------------------------------------------------------------------------------

  - 首次启动后约 3 秒自动拉取 300 条新闻
  - 9 个分类平均分配（约 33-34 条/分类）
  - 每 30 分钟全量刷新（DELETE + INSERT 300 条新数据）
  - 刷新后自动清空 Redis 新闻缓存，下次访问重建
  - 新闻来源：中文 RSS + 内置 495 条标题池兜底
  - 浏览量通过 Redis Hash 累加，每 5 分钟批量写入 MySQL

  修改更新频率：编辑 .env → NEWS_FETCH_INTERVAL（分钟）
  修改新闻数量：编辑 .env → NEWS_TOTAL_COUNT
  修改浏览量入库间隔：编辑 main.py → views_scheduler 的 minutes 参数

六、Redis 缓存监控与调试
================================================================================

--------------------------------------------------------------------------------
6.1  查看缓存命中情况
--------------------------------------------------------------------------------

  进入 Redis 容器：

      docker compose exec redis redis-cli

  常用命令：

      # 查看有多少个缓存键
      DBSIZE

      # 查看新闻相关缓存键数
      KEYS news:* | wc -l

      # 查看当前浏览量计数（未入库的）
      HGETALL news:views:batch

      # 查看内存使用
      INFO memory | grep used_memory_human

      # 查看被淘汰的键数（LRU）
      INFO stats | grep evicted_keys

--------------------------------------------------------------------------------
6.2  手动清除缓存
--------------------------------------------------------------------------------

  # 清除所有新闻缓存（模拟新闻刷新）
  docker compose exec redis redis-cli KEYS "news:list:*" | xargs docker compose exec redis redis-cli DEL

  # 清除某个用户的 Token 缓存
  docker compose exec redis redis-cli KEYS "token:user:*" | xargs docker compose exec redis redis-cli DEL

  # 清除全部缓存（慎用）
  docker compose exec redis redis-cli FLUSHDB

--------------------------------------------------------------------------------
6.3  Redis 不可用时的降级
--------------------------------------------------------------------------------

  项目设计为 Redis 挂了也不影响核心功能：
  - 新闻接口：Redis 异常时直接查 MySQL，不报错
  - Token 鉴权：Redis 异常时降级为纯数据库查询
  - 浏览量：Redis 异常时跳过累加，不影响阅读

七、常见问题排查
================================================================================

  Q: docker compose up -d 提示端口被占用

  A: 本机 MySQL 占了 3306。管理员 PowerShell：

         net stop MySQL
         net stop MySQL80

     如果 80 端口被 IIS 占，docker-compose 已改为 8080。
     如果 6379 端口被本机 Redis 占：

         net stop Redis


  Q: 前端页面空白

  A: F12 → Console 看报错：
     - 连接被拒绝 → 后端没启动（docker compose logs backend 看日志）
     - JS 报错 → Ctrl+Shift+R 强制刷新
     - 接口 404 → Nginx 代理配置或端口问题


  Q: 新闻列表为空

  A: 等 1-2 分钟让首次拉取完成，看日志：

         docker compose logs backend | tail -20

     确认有 "成功插入 300 条新闻"。


  Q: 注册/登录网络错误

  A: 确认是 Docker 构建的前端（VITE_API_BASE_URL=""），
     不要用 localhost:5173 访问 Docker 后端。


  Q: Redis 连接失败

  A: 检查 Redis 容器状态：

         docker compose ps redis

     如果不是 Up，手动启动：

         docker compose up -d redis

     确认 .env 中 REDIS_URL=redis://redis:6379/0（Docker 环境）


  Q: Docker Desktop 无法启动

  A: 确保 WSL2 安装正确：

         wsl --update
         wsl --install

     重启 Docker Desktop。


  Q: 镜像拉取超时

  A: 按 1.3 步骤重新配置镜像加速。


  Q: Windows 本地开发 Redis 连不上

  A: 确认 redis-server.exe 已启动。如果没装 Redis：
     https://github.com/tporadowski/redis/releases 下载解压
     双击 redis-server.exe
     或者直接用 Docker Redis：docker compose up -d redis
